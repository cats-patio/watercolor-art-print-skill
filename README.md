# Vintage Watercolor Art Print Skill

An AI Agent Skill designed to transform standard photos into pristine, vintage hand-painted watercolor art prints framed by a clean white paper border.

## 🌟 Features
* **Authentic Watercolor Aesthetic**: Simulates traditional wet-on-wet watercolor technique, paper textures, and soft color bleeding.
* **Pristine White Border**: Adds a clean, wide paper mat border framing the picture.
* **No Clutter Guarantee**: Specially optimized prompt structure to avoid unwanted stamps, postmarks, text, or graphic overlays.

## 🚀 How to Use

### 1. Direct AI Agent Execution (Prompt)
Copy and send the following prompt to any web-enabled AI Agent (e.g., ChatGPT, Claude, Kimi, Cursor):

> Please load and execute the skill configuration from:
> `https://raw.githubusercontent.com/cats-patio/vintage-watercolor-postcard-skill/main/SKILL.md`
> 
> As the executing Agent for this Skill, analyze my uploaded photo and generate the corresponding watercolor art print.

### 2. Image Generator Prompt (Canva AI / Midjourney / DALL-E 3)
If using an image generator directly, paste this prompt:

> Generate an authentic hand-painted watercolor painting based on this image. Features: soft natural color bleeding, visible wet-on-wet brush strokes, translucent watercolor washes, delicate paper texture, gentle pastel palette, soft dreamy lighting. Presented strictly as a pure fine art watercolor print centered inside a wide, pristine white paper border frame. Clean minimalist aesthetic, blank paper margins, pure illustration only.

## 💡 Prompt Optimization Insight (Why No Postmarks?)
Traditional AI prompts using the word `"Postcard"` often force AI models to generate unwanted postmarks and postage stamps due to strong concept association. 

This skill bypasses that issue by:
1. Replacing the term `"Postcard"` with `"Art print with white paper mat border"`.
2. Avoiding weak negative prompts (like `no stamps`), replacing them with positive clean-state descriptions (`pristine blank margins`, `pure illustration only`).
